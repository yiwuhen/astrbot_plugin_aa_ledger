# 群内 AA 记账（astrbot_plugin_aa_ledger）

群聊里**一句话记一笔**，月底一条命令算出「谁该给谁多少钱」，附带最小转账方案。

聚餐、打车、房租水电、宿舍 AA——凡是「一个人先垫钱，大家平摊」的场景都能用。

## 为什么值得装

- **记账摩擦极低**：`aa 68 午饭` 三个字符就完事，不用打开任何 App
- **支持刷屏式录入**：账本成员在群里说「午饭 68 我先付了」，机器人自动入账
- **AI 也能记**：注册为 AI 工具，接了大模型后「昨天火锅 258 我付的」直接触发，不必背命令
- **一分钱都不会算错**：金额全程以「分」为单位做整数运算，68 元 3 人分摊是 `22.67 / 22.67 / 22.66`，合计严格等于 68.00
- **转账笔数最少**：不是「每个人都转给垫付人」，而是用贪心算法压缩，8 人 8 笔账通常 4 笔转账就能全部结清
- **多群独立**：每个群一本账，私聊还能当个人记账用

## 安装

把 `astrbot_plugin_aa_ledger` 文件夹放进 AstrBot 的 `data/plugins/`，或在 WebUI「插件」页上传 zip。
无第三方依赖，装完可直接用，**不需要任何配置**。AI 工具调用需要模型侧开启 Function Calling（AstrBot 默认开启）。

## 快速开始

第一次用，先把自己加进账本：

```
[你]     aa 加入
[机器人] ✅ 张三 已加入账本（共 1 人）
        从下一笔开始参与平摊。
```

然后记第一笔：

```
[你]     aa 68 午饭
[机器人] ✅ 已记账

        📝 午饭  ¥68.00
        👤 垫付：张三
        👥 分摊：1 人（每人 ¥68.00）
           张三

        账本累计：1 笔 / ¥68.00
        「aa 结算」看方案 ·「aa 撤销」撤回这笔
```

其他人陆续 `aa 加入`，之后每笔记账就自动由**全体成员**平摊。

月底结算：

```
[你]     aa 结算
[机器人] @所有人
        💸 结算方案
        6 笔未结 · 合计 ¥412.00

        1. 王五 → 张三  ¥68.60
        2. 赵六 → 张三  ¥54.40
        3. 李四 → 王五  ¥13.60

        共 3 笔转账即可全部结清
        转完发「aa 清账」把账本归零
        你（张三）应收 ¥123.00
```

## 命令一览

```
aa 加入                  把自己加进当前群的账本
aa                       账本概况（总额、笔数、我的净额）
aa <金额> <描述>          记一笔，你垫付，全员平摊
aa <金额> <描述> @某人    只让被 @ 的人分摊
aa <金额> <描述> 除@某人   全员里排除掉某人
aa 明细                  最近 10 笔流水
aa 结算                  转账方案（别名：结算 / 算账）
aa 清账                  结算后归零（需发「aa 清账 确认」二次确认）
aa 撤销                  撤回最后一笔（限记账人或垫付人）
aa 成员                  成员列表 + 各自待收/待付
aa 归档                  历史已结清的记录
aa 退出                  退出账本（有未结净额时会拒绝）
aa 帮助                  完整命令说明
```

命令别名：`aa` 也可以写成 `记账`。如果 AstrBot 配了唤醒前缀，用 `/aa` 同样可以。

## 金额怎么写都行

| 写法 | 识别结果 |
| --- | --- |
| `aa 68 午饭` | ¥68.00 |
| `aa 68.5 奶茶` | ¥68.50 |
| `aa ¥128 火锅` | ¥128.00 |
| `aa 32元 打车` | ¥32.00 |
| `aa 六十八块 晚饭` | ¥68.00 |
| `aa 两百三 住宿` | ¥230.00 |
| `aa 一百零五 水电` | ¥105.00 |

量词不会被误判：`3个人`、`2份` 都不会被当成金额。

## 分摊规则

| 写法 | 谁分摊 |
| --- | --- |
| `aa 68 午饭` | 账本里的全部成员（含垫付人自己） |
| `aa 68 午饭 @李四 @王五` | 只有李四、王五（张三垫付但不参与） |
| `aa 68 午饭 除@王五` | 全部成员减去王五 |

余数处理：6800 分 / 3 人 → `2267 / 2267 / 2266`，多出的 1 分按顺序分给前面的人，保证合计严格等于总额。

## 自动识别（可选，默认开）

开启后，**账本成员**在群里说下面这类话会自动记一笔：

```
午饭 68 我先付了        → 记 ¥68.00（午餐）
打车花了 32 块          → 记 ¥32.00（打车）
这顿我买单 258          → 记 ¥258.00
```

刻意收紧的规则，宁漏不误：

- 必须同时有「付款线索词」（我付/我买/垫付/买单/结账/花了…）和可识别金额
- 疑问句（`吗`/`？`/`多少`）、假设句（`如果`/`下次`/`应该`）一律不记
- 只有账本成员会触发，路人的闲聊不会被记进账
- 非成员说「我付了 68」不会记账——需要先 `aa 加入`

误记了就发 `aa 撤销`，只能撤自己记的或自己垫付的那笔。

不想用自动识别，在插件配置里把「自动识别群里的消费消息」关掉即可，只用 `aa 68 午饭` 手动记。

## AI 直接调用（Function Calling，默认开）

插件会把记账能力注册成 AI 工具，用户**不用记命令**，正常说话就行——由大模型自己判断该不该调用：

```
[你]     昨天火锅 258 我先付的，一共五个人
[机器人] 记上了，¥258.00，5 人分摊每人 ¥51.60

[你]     刚才那笔记错了，撤掉
[机器人] 已撤销：火锅 ¥258.00

[你]     现在谁该给谁多少？
[机器人] 4 个人各转你 ¥51.60 就结清了
```

| 工具名 | 触发场景 | 模型传参 |
| --- | --- | --- |
| `aa_record_bill` | 「我付了」「帮我记一下」「这顿 AA」 | 金额、消费内容、分摊人（可选）、垫付人（可选） |
| `aa_view_ledger` | 「账本还有多少」「最近记了啥」 | 是否列流水 |
| `aa_settle_plan` | 「算一下谁该给谁」「结一下账」 | 无 |
| `aa_undo_bill` | 「记错了」「刚那笔撤掉」 | 无 |

分摊人可以用自然语言指定，模型会转成参数：「只算我和李四」「除了王五」。

几点说明：

- 需要模型支持函数调用（AstrBot 提供商配置里的 Function Calling，默认开启）
- 指令还是要人先说清楚金额，模型不会凭空编金额；金额模糊时它会反问
- 和「自动识别」不冲突：自动识别命中会先 `stop_event()`，AI 不会重复再记一笔
- 不想让 AI 动账本，把配置项 `llm_tools` 关掉，工具会拒绝执行并提示用命令

## 配置项（全部可选）

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| `llm_tools` | 让 AI 自己记账（注册为 Function Calling 工具） | `true` |
| `auto_capture` | 自动识别群里的消费消息 | `true` |
| `currency` | 金额符号 | `¥` |
| `at_all_on_settle` | 结算时 @所有人（发送失败自动降级为纯文本） | `true` |
| `max_bills_display` | `aa 明细` 最多显示几笔 | `10` |

## 数据存储

```
data/plugin_data/astrbot_plugin_aa_ledger/ledger.json
```

按会话隔离，每个群一本账。该目录不受插件重装/更新影响。
旧版本写在插件目录里的 `ledger.json` 会在启动时自动迁移过来。

## 常见问题

**Q：能不能改已经记错的一笔？**
目前只能撤最后一笔（`aa 撤销`）。要改中间某笔，先撤销到那笔再重记。这是刻意的取舍——账本最怕的是「悄悄被改」，宁可让操作笨一点。

**Q：张三退出后他之前的账怎么算？**
退出时会检查净额，有欠款或待收会拒绝退出，必须先结清。所以账本里不会出现「找不到人的欠款」。

**Q：多人同时记账会冲突吗？**
不会。读写都是同步的 JSON 操作，中间没有 await 点，不会交错。群聊这种频率完全够用。

**Q：转账笔数是最少的吗？**
严格最少笔数是 NP-hard 问题，插件用的是贪心（每次让欠最多的还给收最多的），在 AA 记账这种规模下已经是最优或极接近最优。

**Q：私聊能用吗？**
能，私聊会当作一份独立的个人账本，适合记自己的开销。
